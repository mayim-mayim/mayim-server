# ln-church-server v1.11.2 — Security Dependency Update

Version 1.11.2 raises the production Hono dependency floor to `^4.12.30`. This prevents fresh installs of `@ln-church/hono` and the bundled starter workspace from resolving to Hono versions affected by the reported high-severity runtime advisory.

The release also updates the development and production-bundle toolchain to Wrangler `^4.112.0`, Vitest `^4.1.10`, and `@vitest/ui` `^4.1.10`. The regenerated lockfile resolves Vite and related transitive build dependencies outside the reported vulnerable ranges, and both full and production-only npm audits complete without findings.

All five public LN Church Server packages, the workspace lockfile, runtime manifests, and generated Hono declarations use version `1.11.2`. The version-consistency test checks the declared dependency ranges and the locked and installed security floors.

The Wrangler production-bundle regression test converts file URLs with the platform-aware Node API and invokes the Wrangler JavaScript CLI through the active Node executable. This keeps the same production bundle assertions while supporting both Linux and Windows paths.

Payment verification, canonical requirement binding, atomic replay protection, manifest behavior, and privacy boundaries are unchanged from version 1.11.1. This source release does not publish packages to npm.
